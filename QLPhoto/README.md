主应用通过辅助功能提供 Finder 空格预览。Extension 为实验性静态 Quick Look 预览，不保证系统优先选择该扩展。

从仓库根目录运行 `bash scripts/build.sh` 和 `bash scripts/check.sh`。工程由 `project.yml` 描述，已提交共享 scheme 和生成的 Xcode 工程。
